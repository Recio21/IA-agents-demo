# IA-agents-demo

Proyecto de demostración: IA-agents-demo

Descripción
- Repositorio de ejemplo para experimentar con agentes de IA.

Archivos iniciales
- `main.py`: ejemplo mínimo para arrancar.

Cómo usar
1. Clonar o crear remoto en GitHub (ver instrucciones abajo).
2. Ejecutar localmente:

```powershell
python main.py
```

Crear el repo remoto (opciones):
- Usando GitHub CLI (si estás autenticado):

```powershell
gh repo create Recio21/IA-agents-demo --public --source=. --remote=origin --push
```

- O crea el repo en https://github.com/new y luego:

```powershell
git remote add origin https://github.com/Recio21/IA-agents-demo.git
git push -u origin main
```
